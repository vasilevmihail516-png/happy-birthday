# FOR RITA 5.13

Статический сайт-подарок для Риты. Запуск: распаковать архив и открыть `index.html` в современном браузере. Для публикации загрузить содержимое папки на статический хостинг.

## Что есть на сайте

- HOME — персональное приветствие и GIF с объятием.
- Счётчик до 10 декабря 2026 года и счётчик дружбы с 2 июня 2026 года.
- THE LOCK — 10 последовательных этапов.
- SECRET BLOCK — история подготовки сайта, открывается после девятого этапа.
- OPEN WHEN — 10 переворачивающихся карточек; по 5 вариантов текста на каждую. Варианты выбираются случайно и не повторяются в рамках карточки, пока не будут показаны все пять.
- RANDOM — случайные персональные напоминания.
- MUSIC — локальный аудиоплеер: выбранный файл не загружается на сервер и после перезагрузки выбирается заново.
- BIRTHDAY — праздничный экран с предварительным просмотром и автоматическим показом 10 декабря.
- OUR STATISTICS — общие цифры из выгрузки переписки, подключённые через `stats-data.js`.
- THE FINAL — 10 заданий по деталям переписки.
- THE FINAL — место для личного текста автора.

## Технические заметки

- HTML, CSS и JavaScript; PHP и серверная база данных не требуются.
- Прогресс и настройки темы сохраняются локально в браузере.
- Сброс THE LOCK доступен внизу соответствующего блока для тестирования.
- Локальное хранилище браузера не синхронизируется между устройствами.
- Для проверки JavaScript можно выполнить `node --check` для файлов `.js`.
